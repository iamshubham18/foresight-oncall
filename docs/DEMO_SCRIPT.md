# Demo script (3 minutes)

**Story:** "It is 2 a.m. Payments is down. Watch what the agent knows that a fresh chatbot does not."

| Time | Show | Say |
|---|---|---|
| 0:00 | Title + one sentence | "On-call engineers re-learn the same outages. This agent remembers them." |
| 0:20 | Demo alert 1, **memory OFF** | "Without memory: generic advice. Check logs, restart the service." |
| 0:50 | Same alert, **memory ON** | "Same alert. It cites INC-0388, says restarts only bought 15 minutes, and flags a different cause to rule out." |
| 1:30 | Memory panel | "Every claim traces to a retained memory. Different wording, same failure." |
| 1:50 | Demo alert 4 (unseen) | "When it has no history, it says so instead of guessing." |
| 2:10 | Feedback form, submit a correction | "I tell it what really fixed this one. That goes straight into Hindsight." |
| 2:30 | Re-run the alert | "Now the answer includes today's lesson." |
| 2:45 | Hindsight UI at :9999 | "This is the memory bank behind it." |
| 2:55 | Close | "Every incident makes the next one shorter." |

## Prep checklist
- Hindsight running and seeded, Groq key valid, `smoke_test` passed
- Browser zoom ~125%, notifications off
- Backup recording ready in case of live failure
