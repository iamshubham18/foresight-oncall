# Submission checklist (keep out of the public repo; listed in .gitignore)

## Rules that cause disqualification
- The word "hackathon" must NOT appear in the article title/body, hashtags, or the LinkedIn post.

## Project
- [ ] GitHub repo public, clean README, docs/ folder
- [ ] Demo video (2-5 min), 1080p+, on YouTube (public) with a thumbnail
- [ ] Live demo rehearsed; backup recording ready
- [ ] Written explanation of Hindsight usage (`docs/HINDSIGHT_USAGE.md`)
- [ ] Band AI desktop: required in the brief; skipped for the online round by choice. Confirm the submission form does not ask.

## Content (each team member)
- [ ] Article 800-1,500 words, public (Medium / Dev.to / Hashnode / Substack / LinkedIn Article)
  - [ ] Title about the idea or result, not the event
  - [ ] Includes links: Hindsight GitHub, Hindsight docs, Vectorize agent-memory page
  - [ ] >= 1 real code snippet, >= 1 before/after example, >= 1 honest limitation, screenshots
- [ ] LinkedIn post (< 800 chars), 3-5 hashtags on the last line only, repo link in the post body
  - [ ] First comment: article URL; second comment: https://github.com/vectorize-io/hindsight
  - [ ] Tag Code.in
- [ ] Reddit link post of the article in one of: r/llmdevs, r/sideproject, r/aiagents, r/aimemory
- [ ] Video thumbnail (16:9)

## Final
- [ ] All links open while logged out
- [ ] No API keys committed (`.env` ignored)
